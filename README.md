## What is Void SMS?

Void SMS provides temporary US phone numbers to receive SMS verification codes without exposing your personal phone number. Perfect for:

- 🔒 **Protect your privacy** - No link between your real number and your accounts
- 📱 **Multiple verifications** - One disposable number per service
- ⚡ **Fast delivery** - Receive codes in seconds
- 🇺🇸 **US numbers** - For services requiring American numbers

## How It Works

### 1. Buy Credits

### 2. Select Service

Choose the service you need verification for (Instagram, Telegram, Netflix, etc.).

### 3. Receive Number

The bot provides a temporary US number. Enter it in the service you're verifying.

### 4. Get Code

The SMS code arrives automatically in the bot within minutes.

## Security & Encryption

### 🛡️ Data Protection

All sensitive data is protected with **AES-256-GCM encryption**, a military-grade standard used by banks and governments.

```
Algorithm: AES-256-GCM
Key derivation: PBKDF2 with 100,000 iterations
IV protection: Random 96-bit for each operation
```

### 🔑 Key Management

- Encryption keys are stored securely and **never accessible** to personnel
- Each data is isolated with a unique initialization vector (IV)
- Versioning system for future key rotation

### 🚫 What We DON'T Store

- ❌ Purchased phone numbers
- ❌ Content of received SMS
- ❌ Personal data
- ❌ IP addresses
- ❌ Browsing logs
- ❌ Verification history

### ⚠️ Important Note on Blockchain

Bitcoin transactions are public and permanent on the blockchain. If you pay with BTC, anyone can see your address on the blockchain.

## FAQ

### How long do I have to receive the SMS?
You have **10 minutes** once you receive the number. If no SMS arrives, the number is released automatically and nothing is charged.

### What if the number doesn't work?
You can cancel the order and request a new number. No credits will be deducted.

### Can I use the same number for multiple services?
Each number is for a single service. For multiple verifications, you'll need separate numbers.

### Are the numbers from the US?
Yes, we provide exclusively US numbers.

### Can I get a refund?
Purchased credits are non-refundable. Make sure to buy the right amount for your needs.
